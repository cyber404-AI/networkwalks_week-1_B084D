# Week 1 Evidence Checklist

Use this checklist to track evidence collected from my own Kali Linux VM.

| Requirement / check | Evidence to add | Status |
|---|---|---|
| Hypervisor and version | Screenshot or version output | completed |
| Kali VM resource settings | VM settings screenshot |completed |
| Active network interface and IP | `ip -br addr` output | completed|
| Default gateway and route | `ip route` output | completed |
| DNS configuration | Resolver status/output | completed |
| Gateway connectivity | Ping output | completed |
| External IP connectivity | Ping or approved connectivity test | completed |
| DNS resolution | `getent hosts example.com` output | completed |
| Shared folder configuration | Hypervisor settings screenshot | completed |
| Shared folder access | Mount and permission checks | completed |
| Snapshot / recovery point | Snapshot listing screenshot, if created | completed|
